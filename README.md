
# Student Task Manager

A simple Student Task Manager developed using Python.

## About the Project

Student Task Manager is a Python-based project designed to help students
manage their academic tasks and stay organized.

## Features

- Simple Python application
- Student task management project
- Easy to run and understand

## Technologies Used

- Python

## Getting Started

### Prerequisites

- Python 3 installed

### Installation

1. Clone the repository:

   git clone https://github.com/shruta99-cse/Student-Task-Manager.git

2. Open the project folder:

   cd Student-Task-Manager

3. Run the application:

   python app.py
